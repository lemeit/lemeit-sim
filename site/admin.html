Operación y recuperación

Operación y recuperación

Ejecutar los comandos individualmente en el equipo correspondiente. No detener durante cálculos activos ni borrar .local/runtime. No compartir claves ni tokens. Windows online 5911; Debian 5910; MCP HTTP Debian 5901.

Windows · iniciar y detener
cd C:\GitHub\lemeit-sim
powershell -ExecutionPolicy Bypass -File .\start-online.ps1 -EngineRoot "C:\GitHub\lemeit-sim\.local\runtime"
# Detener (solo sin cálculos activos):
powershell -ExecutionPolicy Bypass -File .\stop-online.ps1 -EngineRoot "C:\GitHub\lemeit-sim\.local\runtime"
Windows · diagnóstico y actualización
Invoke-RestMethod http://127.0.0.1:5911/api/status
Invoke-RestMethod http://127.0.0.1:5911/api/dynamics/capabilities
Get-Content .\.local\runtime\public-gateway.stderr.log -Tail 50
Get-Content .\.local\runtime\tunnel.stderr.log -Tail 50
# Detener antes de actualizar; comprobar árbol limpio:
git status -sb
git fetch origin
git pull --ff-only origin main
python -m unittest tests.python.gateway.test_dynamic_tank_mcp -v
Windows · inicio automático
powershell -ExecutionPolicy Bypass -File .\enable-autostart.ps1
# Para desactivar:
powershell -ExecutionPolicy Bypass -File .\disable-autostart.ps1
Debian · servicio y diagnóstico
sudo systemctl status lemeit-sim.service
systemctl show lemeit-sim.service -p WorkingDirectory
sudo systemctl start lemeit-sim.service
# Para detener o reiniciar (elegir una acción):
sudo systemctl stop lemeit-sim.service
sudo systemctl restart lemeit-sim.service
sudo systemctl enable lemeit-sim.service
curl -sS http://127.0.0.1:5910/api/status
curl -sS http://127.0.0.1:5910/api/dynamics/capabilities
sudo journalctl -u lemeit-sim.service -n 50 --no-pager
ss -ltnp | grep -E ':5901|:5910'
pgrep -x cloudflared
Debian · actualizar y probar
# Entrar en WorkingDirectory y verificar árbol limpio.
# Detener gateway sin cálculos activos antes de actualizar.
git status -sb
git fetch origin
git pull --ff-only origin main
python3 -m unittest tests.python.gateway.test_dynamic_tank_mcp -v
sudo systemctl restart lemeit-sim.service
python3 tools/probe_dynamic_tank.py --run
Windows · servidor local
cd C:\GitHub\lemeit-sim
powershell -ExecutionPolicy Bypass -File .\start-local.ps1 -EngineRoot "C:\GitHub\lemeit-sim\.local\runtime" -Port 5910
# Abrir http://127.0.0.1:5910; detener con Ctrl+C.
