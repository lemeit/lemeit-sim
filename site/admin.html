Recuperación local de servicios

Acciones de recuperación local

Estos comandos deben ejecutarse en el equipo correspondiente. El portal no ejecuta órdenes administrativas ni intenta encender computadoras apagadas.

Windows · PowerShell

cd C:\GitHub\lemeit-sim
.\start-online.ps1
# Si se actualizó server.py y hay un gateway anterior:
.\stop-online.ps1
.\start-online.ps1
Invoke-RestMethod http://127.0.0.1:5911/api/status

Debian · terminal

cd ~/lemeit-sim
sudo systemctl status lemeit-sim.service --no-pager
sudo systemctl restart lemeit-sim.service
curl -s http://127.0.0.1:5910/api/status

Si Debian está apagada, el servidor no puede iniciarse mediante este panel; primero hay que encender la notebook. Reiniciar un gateway puede interrumpir un cálculo que esté en curso.
