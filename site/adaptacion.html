Qué falta para la cinética

La auditoría del runtime Windows DWSIM MCP 10.2.15 encontró herramientas para crear reacciones de conversión y equilibrio, pero ninguna herramienta específica para definir una reacción cinética. El portal actual tampoco expone CSTR/PFR. La próxima etapa requiere ampliar o adaptar ese acceso antes de mostrar estos equipos como calculables.

Para una reacción cinética se necesitan ecuación balanceada, fase, ley de velocidad, unidades, parámetros, dependencia con temperatura, fuente y rango de validez. La base de compuestos no reemplaza esos datos. No se inventan constantes.

Un PFR estacionario puede tener perfiles con posición o volumen sin representar un transitorio temporal. Un batch evoluciona en el tiempo. Los gráficos deberán distinguir ambas variables.

Herramientas para gases y composición

Herramientas → Calculadora permite convertir fracciones y caudales con masas molares, calcular pᵢ = yᵢ P absoluta y estimar concentraciones bajo hipótesis de gas ideal. Esto no integra una reacción ni sustituye las fugacidades del modelo termodinámico.

Configuración selecciona SI, ingeniería o anglosajón. Las presiones del proceso siempre son absolutas; la calculadora convierte manométricas con una presión atmosférica explícita.
